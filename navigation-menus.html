14.1 Menu Engine Architecture & Multi-Location Routing

MartX is engineered with an enterprise Multi-Location Dynamic Menu Engine. Instead of hardcoding hyperlinks into frontend templates, all navigation bars across the website are managed dynamically through a centralized, high-performance database-driven system.

Admin Access Path

Navigate to: Admin Dashboard → Website & CMS → Menu Builder.

Supported Menu Locations in MartX:
header_top_menu
Header Top Utility Menu

Appears in the upper announcement strip. Used for quick utility links like FAQs, Order Tracking, Wishlist, and Terms & Conditions.

footer_company
Footer Column 1 (Company)

First primary navigation column in the store footer. Typically displays About Us, Store Locations, Careers, and Privacy Policy.

footer_support
Footer Column 2 (Support)

Second primary footer navigation column. Ideal for Customer Support, Shipping Guide, Return Policy, and Helpdesk.

High-Performance Eager Loading (Zero N+1 Queries)

The MartX menu service (App\Services\Admin\MenuService) utilizes optimized eager loading (Menu::with('items')). Whether your storefront renders 5 menus or 50 items simultaneously, the entire menu tree loads in a single, blazing-fast database query.

14.3 The Four Core Item Source Tabs

To give store owners complete linking versatility without requiring manual URL lookups, the Menu Builder divides link sources into 4 dedicated tabs:

Tab 1
System Pages

Connects directly to pre-configured named routes inside Laravel. Ensures links never break even if the site URL or domain changes.

Supported: Home (root), Shop (shop), About Us (about), Contact Us (contact), Flash Sales, Wishlist, Cart, FAQs, Blogs.
Tab 2
Dynamic Pages (CMS)

Dynamically loads all published pages from the MartX CMS Engine (Page::all()).

Automatically populates: Terms & Conditions, Privacy Policy, Shipping Policy, Refund Terms, and custom CMS pages.
Tab 3
Categories (Catalog)

Links directly to e-commerce product categories. Shoppers clicking these items are taken straight to the filtered category catalog.

Inherits category slugs automatically with live product counts.
Tab 4
Custom Links

Enables linking to external domains, partner websites, helpdesk portals, or internal page anchors (#section-id).

Required fields: Target URL (https://...) and Link Title.

14.4 Footer Column Titles & Menu Rename Engine

In your storefront's footer, links are organized into structured columns (e.g. Footer - Company and Footer - Support). MartX provides an exclusive Context-Aware Menu Rename Engine that empowers administrators to rebrand these column header titles without touching template code.

Admin Modal — Rename Footer Menu Title
Rename Engine
images/menus/admin_menu_rename_modal.png
Context-Aware Trigger: Selecting "Footer - Company" or "Footer - Support" dynamically displays the "Rename" pill button in the top-right corner.
How to Customize Footer Column Headings:
  1. From the Menu Selector dropdown, choose either "Footer - Company" or "Footer - Support".
  2. Notice the Rename button automatically appear in the top-right corner of the right card.
  3. Click Rename to open the Rename Menu modal.
  4. Update the Menu Name * field (e.g. change Company to About MartX, or Support to Customer Care).
  5. Click Save Changes. The column heading updates immediately in both the admin interface and the live storefront footer.

14.6 Drag & Drop Ordering & Live AJAX Serialization

Managing menu sequence in MartX is effortless. The left-hand menu tree integrates an interactive HTML5 Drag-and-Drop Sortable Engine:

Reordering Workflow
  1. Hover your cursor over any menu item in the left list.
  2. Click and hold the item, then drag it vertically up or down to your desired sequence position.
  3. Release the mouse button to drop the item in place.
  4. The engine automatically synchronizes the new sequence in the background, updating the database order instantly without requiring a manual save.
Real-Time Persistence Highlights
  • Zero "Save Order" Clicks: Order updates save automatically the moment you release the item.
  • Session State Memory: Remembers your active menu selection across browser refreshes via localStorage.
  • Instant Frontend Reflection: Refreshing the store homepage immediately displays the updated navigation order.

14.7 Mobile Navigation Sync & Best Practices

A seamless navigation experience directly impacts store conversions. MartX ensures your menus deliver optimal usability across every device:

Automated Mobile Drawer Sync

Items configured in your Header Top Menu and Main Menu automatically adapt into the responsive mobile offcanvas drawer on smartphones and tablets, offering smooth touch accordion navigation without duplicate management.

Recommended Item Counts

Keep the Header Top Menu between 3 to 5 items to avoid visual crowding. For the Footer Columns, 4 to 6 items per column creates balanced, aesthetically pleasing footer symmetry.

Pro-Tip for Multilingual Stores

When configuring menu link titles for an international customer base, keep titles concise (1 to 2 words, e.g. "Track Order", "Deals", "Support"). This ensures links render comfortably across varied language character lengths and mobile viewports.

14.8 Mega Menu Configuration & Layout Engines (Layout 1 & Layout 2)

In addition to linear header and footer menus, MartX features an enterprise Mega Menu Content Engine located under Website & CMS → Mega Menu. While Chapter 6 (Theme Layouts Hub) enables you to choose your active architectural style (Layout 1 vs Layout 2), this module provides a dedicated, context-aware management dashboard for featured categories, promotional banners, and real-time frontend simulation.

Admin Access Path & Dynamic Engine Switching

Navigate to: Admin Dashboard → Website & CMS → Mega Menu.
The admin workspace dynamically adapts its form fields, layout parameters, and live preview simulator depending on whether your active store layout is configured as Mega Menu Layout 1 or Mega Menu Layout 2.

LAYOUT 1 Seasonal Promotional Banner & Hover Flyout Architecture

Split 3-column navigation featuring parent categories, interactive hover-activated subcategories, and a dedicated campaign promo card.

Header 1 & Header 2 Compatible
Admin Panel — Mega Menu Layout 1 (Promotional Banner & Hover Flyout)
Layout 1 Active
images/menus/admin_megamenu_settings_layout1.png
Layout 1 Control Hub: Manage featured categories with interactive tag badges, upload campaign promotional banners with custom link targets, and inspect subcategories in the real-time interactive simulator.
Layout 1 Feature Breakdown:
1
Active Layout Strip & Quick Switcher

Displays the current active layout badge (LAYOUT 1) alongside an instant shortcut button (Switch Layout in Theme Layouts) allowing 1-click transit between configuration hubs.

2
Featured Categories Selector & Tags

Pick up to 6 root categories. Selected items appear as purple pill badges with 1-click removal cross buttons (Men's Fashion ×) and a live counter badge (7 / 6 Selected).

3
Campaign Promotional Banner Uploader

Upload eye-catching campaign imagery (e.g. Seasonal 50% Off Sales). Clicking Select Banner connects to the MartX Media Manager for fast selection with instant high-res preview.

4
Dynamic Banner Link Destination

Binds the promotional banner to any desired URL: pick a System Page (Shop, Deals), a specific Product Category, a CMS Page, or an external marketing URL.

Layout 1 Interactive Simulator Columns:
Left Column (Categories): Lists selected parent categories vertically. The active category is visually highlighted with an accent container.
Center Column (Hover Flyout): Hovering over any parent category dynamically updates the center column with its live child subcategories.
Right Column (Promo Banner): Renders the promotional campaign graphic with smooth hover elevation and full-card link clickability.

LAYOUT 2 Multi-Column Categorized Directory Grid Architecture

Direct directory navigation displaying category thumbnail icons, top 5 subcategories per card, and auto-computed responsive grid columns.

Directory Style • No Banner Needed

Layout 2 Directory Hub: Features a top-stacked category selector, dynamic column auto-calculation, category thumbnail icons with letter avatar fallbacks, and a full-width (col-12) live directory grid simulator.
Layout 2 Engineering Highlights:
1
Top-Stacked Full-Width Category Selector

The category selection form is engineered in a clean, full-width top block. Admins select up to 6 featured categories without horizontal clipping, with purple pill tags and 1-click removal (Electronics ×).

2
Dynamic Multi-Column Auto-Calculation

The directory grid intelligently calculates its responsive column layout based on the number of categories chosen: 1–2 items = 2 columns, 3–4 items = 3 columns, and 5–6 items = 4 balanced columns (mega-grid-cols-4).

3
Dual Category Icon Engine (Image & Fallback Avatar)

Renders genuine category thumbnail images from the Media Library. If no image exists or if media fails to load, it automatically generates a modern, high-contrast Letter Avatar fallback (e.g. E for Electronics, M for Men's Fashion).

4
Direct Subcategories & "View All" Deep Link

Unlike Layout 1 which requires hover activation, Layout 2 instantly presents the top 5 child subcategories directly inside each category column, accompanied by an automated "View All (x) →" link navigating to the category archive.

Full-Width Live Directory Grid Simulator:

Positioned directly below the selection controls in a dedicated full-width container, the simulator mirrors the exact frontend CSS grid styling, category icons, subcategory lists, and responsive spacing in real time.
