Chapter 21: Master Settings Hub (Brand, Appearance, Currency & Security)

Welcome to the MartX Merchant Cockpit. After completing the initial 5-step installer, your first destination is the System Settings Suite (accessible via Admin Sidebar → System Settings). Configure your store branding, logos, currency format, SMTP email delivery, Gemini AI assistant, security shields, and license bindings in under 5 minutes without writing a single line of code.

Navigate to: Admin Sidebar → System Settings → "General Settings" (Tab). This panel manages your core brand metadata, regional timezones, contact information, dynamic copyright footer, and all 4 official storefront logos via the MartX Reusable Media Library.

21.4 SMTP Mail Server Setup & Port Matching Blueprints

Navigate to: Admin Sidebar → System Settings → "Mail Settings" (Tab). Reliable email delivery is vital for customer order receipts, 2FA login verification codes, and password resets. MartX provides built-in blueprints for cPanel Webmail, Personal Gmail, and Transactional Relay Gateways (Brevo, Resend, Mailgun).

Admin Panel — SMTP Mail Server Configuration Tab
SMTP Relay
images/settings/admin_settings_mail.png
Mail Settings Workspace: Live outbound SMTP gateway manager featuring Mail Host, Port, Username, App Password encryption, SSL/TLS protocol toggle, default sender From Address, and real-time validation.
Built-in SMTP Provider Blueprints:
1. Live Hosting Webmail: Host: mail.yourdomain.com | Port: 465 | Encryption: SSL
2. Personal Gmail: Host: smtp.gmail.com | Port: 465 | Encryption: SSL (Requires 16-digit Google App Password)
3. Transactional Relays (Brevo / Resend / Mailgun): Host: smtp-relay.brevo.com | Port: 587 | Encryption: TLS
Field Name & Type What to Enter & Configuration Rules Storefront Impact & Capability
Mail Host
Hostname / IP		 Your outgoing mail server.
e.g., smtp.gmail.com or mail.yourdomain.com		 SMTP Handshake
Establishes the secure socket connection for outgoing transactional emails.
Mail Port & Encryption
Port Number + Protocol		 Crucial Port Matching Rule:
• Port 465 → Must select SSL
• Port 587 → Must select TLS		 SSL/TLS Transport
Prevents timeout connection errors by pairing the correct cryptographic encryption layer with the corresponding firewall port.
Mail Username
Username / Email		 Your full email address or account username. SMTP Auth
Authenticates your store's sending credentials against the mail server.
Mail Password
Secret Password		 For Gmail: Generate a 16-character App Password from your Google Security account (regular password will fail due to 2FA).
For Webmail: Enter your mailbox password.		 Secure Relay
Stored securely and masked in the database. Never exposed publicly on the storefront.
Mail From Address
Sender Email		 The sender email address shoppers see.
e.g., orders@yourdomain.com		 Inbox Sender Reputation
Matches your domain's SPF/DKIM DNS records to prevent emails from ending up in customer spam folders.

Read-Only Card		 Displays your verified purchase code with masked middle digits (XXXX-****-****-XXXX), registered marketplace, and bound domain. Authentic Verification

🔒 Role & Permission Security (Settings Suite)

The entire System Settings Suite is strictly protected by MartX's enterprise Role & Permission architecture. Unauthorized staff members cannot view or alter configurations. Only team members explicitly granted the System Setting Access permission in Staff & Role Management can modify store branding, currencies, SMTP mail delivery, or security credentials.
