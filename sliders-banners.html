15.1 Visual Marketing Engine Architecture

In modern high-conversion e-commerce, the top fold of the storefront dictates customer first impressions and click-through rates (CTR). MartX separates visual marketing into two distinct, high-performance engines:

1. Hero Promo Sliders Engine
Homepage Hero Carousel

Powers the primary animated hero carousel at the very top of the homepage. Supports multi-slide rotating banners, promotional badges (e.g. "New Season Drops"), customizable headlines, subtitles with responsive 240px wrapping, and flexible Call-To-Action (CTA) buttons with dynamic link binding.

  • Optimal Image Ratio: 21:9 ultra-wide banner (e.g., 1200x500 px).
  • Reordering: Live drag-and-drop table serialization.
  • Visibility: Independent Active / Inactive status flags.
2. Promotional Banner Offers Engine
Seasonal Promotion Cards

Drives the secondary high-impact promotional offer cards positioned directly below or alongside featured sections. Divided into Banner Offer 1 and Banner Offer 2, tailored with transparent PNG imagery, seasonal discounts, and automated layout context rules.

  • Optimal Image Ratio: 1:1 square graphic (500x500 px) with transparent PNG.
  • Dual Tab Setup: Dedicated tabs for Offer 1 and Offer 2.
  • Home Layout Awareness: Auto-locks Offer 2 when Home 2 is active.
Admin Access Routes
  • Hero Sliders: Admin Dashboard → Website & CMS → Sliders
  • Banner Offers: Admin Dashboard → Website & CMS → Banner Offers

15.2 Sliders Management Workspace

The central slider management table provides store managers with an instant visual inventory of all homepage hero carousels. Admins can view banner graphics, verify promotional badges, inspect subtitle messaging, toggle active statuses, and initiate 1-click drag-and-drop reordering.

Table Column Structure & UI Features:
1. SL & Drag Handle

Features a drag-and-drop icon () with an interactive grab cursor. Displays current numeric sequence order (1, 2, 3...) that dynamically updates upon drop.

2. Preview Image

Renders a 190px wide thumbnail preserving the 21:9 cinematic aspect ratio. Features smooth hover zoom (premium-zoom) for instant graphic verification.

3. Title & Button CTA

Displays the main marketing headline in bold text alongside a small CTA badge indicating button text (e.g. Shop Collection).

4. Sub Title (240px Wrap)

Engineered with a dedicated max-width: 240px; and 2-line clamp safeguard. Prevents long promotional sentences from stretching the table width while displaying full tooltips on hover.

5. Badge Text

Displays promotional pill highlights (e.g. New Season Drops or Trending Now). Shows a dash (—) if no badge is set.

6. Status & Actions

Shows a pill badge (Active / Inactive) alongside a 3-dots dropdown menu providing Edit and Delete actions with SweetAlert2 confirmation.

15.3 Drag & Drop Sequence Ordering & AJAX Serialization

MartX eliminates tedious numeric order typing. Sliders can be rearranged instantly via native HTML5 Drag-and-Drop powered by Sortable.js:

Reordering Execution Flow
  1. Click and hold any row in the slider table (or touch the drag handle on mobile).
  2. Drag the slider vertically up or down to your desired display rank.
  3. Release the mouse button to drop the slide into place.
  4. The system instantly saves the updated display sequence in the background without requiring any manual "Save" click.
  5. SL sequence numbers (1, 2, 3...) recalculate dynamically, and a green success Toastr confirmation confirms database synchronization.
Responsive Multi-Device Reordering

Unlike traditional admin panels that disable sorting on mobile devices, MartX features a dedicated touch-friendly accordion drag engine for smartphones and tablets:

Desktop Display (≥ 1200px): The entire table row (.dash-table tbody tr) acts as an active grab zone with visual drop shadows.
Mobile Display (< 1200px): A dedicated touch grip icon (.mdi-drag-vertical) enables smooth touch-based sorting without interfering with accordion click-to-expand behaviors.

15.5 Promotional Banner Offers Engine (Banner Offer 1)

In addition to rotating hero sliders, MartX incorporates a dedicated Promotional Banner Offers Module located under Website & CMS → Banner Offers. These fixed promotional cards showcase targeted seasonal promotions, flash vouchers, and category spotlights.

Admin Panel — Banner Offers Hub (Banner Offer 1 Active)
Offer 1 Tab
images/sliders/admin_banner_offer_1.png
Banner Offer 1 Details: Configures campaign title (e.g. "Spring Exclusive Sale"), sub-title ("Up to 60% off"), dynamic category link binding (Eyewear & Accessories), banner status, and transparent PNG portrait media.
Banner Offer 1 Architecture:
Campaign Title & Discount Subtitle

Craft clear discount messaging (e.g., Title: "Spring Exclusive Sale" | Subtitle: "Up to 60% off"). The frontend renders these with bold contrast typography over accent colored cards.

Dynamic Destination Link Binding

Direct customers straight to high-converting landing pages: select Category → Eyewear & Accessories, a dedicated CMS Page (e.g. Spring Deals), or a custom seasonal clearance URL.

1:1 Transparent PNG Banner Graphic

Unlike wide hero sliders, promotional banners use a 1:1 square ratio (500x500 px). Using transparent PNG backgrounds allows the model or product graphic to seamlessly blend with the card background theme.

Unified Multi-Tab Save Action

Clicking the purple Save All Changes button at the bottom saves both Banner Offer 1 and Banner Offer 2 simultaneously in a single, atomic database transaction.

15.6 Banner Offer 2 & Critical Home 1 vs Home 2 Architectural Rule

Clicking the second pill tab in the banner manager reveals Banner Offer 2. In MartX, Banner Offer 2 is engineered with an intelligent Theme Layout Context Rule that prevents layout distortions across different homepage designs.

Admin Panel — Banner Offers Hub (Banner Offer 2 Active)
Offer 2 Tab
images/sliders/admin_banner_offer_2.png
Banner Offer 2 Details: Features campaign parameters ("Luxury Designer Watches", "Handcrafted Precision & Minimalist Aesthetics", System Page Link) with high-res portrait media.
Critical System Rule: Home 1 vs Home 2 Banner Offer Incompatibility

When your active storefront layout is set to Home 2 (in Chapter 6: Home Layouts Hub), Banner Offer 2 is automatically disabled and locked in the admin panel!

In Home 1 (Multi-Section Grid): Both Banner Offer 1 and Banner Offer 2 are active and displayed side-by-side as dual complementary promotional cards across the main content flow.
In Home 2 (Full-Width Showcase): Home 2 features an exclusive single full-width hero showcase banner powered exclusively by Banner Offer 1. Banner Offer 2 is suppressed to maintain geometric balance.
Automated Admin UI Protection When Home 2 is Active:

To eliminate store manager confusion, MartX automatically enforces the following interface behaviors when Home 2 is selected:

Pill Tab Badge

The Banner Offer 2 tab header displays a bright red badge: Inactive in Home 2.

Context Alert Box

Displays an informative alert banner: "Notice: Banner Offer 2 is Inactive in Home 2 Layout" explaining the full-width single-banner architecture.

Fieldset Lock

All input fields, dropdown selectors, and media buttons in Tab 2 are locked with disabled and 55% opacity styling to prevent accidental edits.

15.7 Optimization & Conversion Best Practices

Follow these enterprise design recommendations to achieve optimal page speed performance and maximum customer click-through rates:

WebP Asset Format

Upload visuals in modern WebP format. WebP delivers 30% smaller file sizes than JPEG with identical visual clarity, protecting Google PageSpeed scores.

3 to 5 Slides Limit

Avoid carousel bloat. Keeping hero sliders between 3 to 5 slides maximizes customer attention while keeping first-contentful-paint (FCP) lightning fast.

Action-Driven CTAs

Use clear, high-intent action verbs for button labels: "Shop New Drops", "Claim 50% Voucher", or "Explore Footwear" rather than generic words.

Mobile Center Focal

When designing graphics, keep key subjects (models, shoes, watches) towards the center. This guarantees they remain focal on narrow mobile viewports.
