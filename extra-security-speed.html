Chapter 23: Extra Security & Speed Boost

Elevate your MartX e-commerce storefront into an enterprise-grade digital fortress. By coupling your hosting server with Cloudflare's global Anycast edge network, you unlock military-grade origin IP protection, sub-50ms worldwide asset delivery, automated bot mitigation, and free lifetime Universal Wildcard SSL.

23.1

High-Impact Advantages: What You Gain

Connecting Cloudflare to your store is not merely an optional enhancement—it is an indispensable architectural shield that fundamentally upgrades your store's security posture and customer browsing speed:

Origin IP Concealment

Your origin hosting server's real IP is completely hidden behind Cloudflare. Malicious actors, SYN flood attacks, and direct port scanners can never touch your actual server.

Sub-50ms Edge Caching

Store catalog images, CSS, JavaScript, and WebP assets are served from 300+ worldwide edge locations closest to your buyers, slashing mobile latency and boosting conversions.

Universal Wildcard SSL

Instant, automated lifetime SSL certificates that guard both your root domain (yourstore.com) and every subdomain (demo.yourstore.com) with zero manual renewal hassle.

Zero Server Overload & Crash Prevention

Offloads up to 80% of bandwidth and web requests away from your origin server. Even if thousands of concurrent buyers surge into a flash sale, your cPanel or VPS RAM and CPU will remain smooth and unburdened.

Automated Bot & Scraping Mitigation

Cloudflare's machine-learning Bot Fight Mode silently identifies and blocks malicious content scrapers, price harvesters, and automated credential-stuffing attacks in real time.

23.2

Step 1: Connecting Your Domain

To begin, log into your Cloudflare Dashboard and initiate domain provisioning:

Walkthrough:
  1. Click the blue "Add a domain" or "+ Add a site" button.
  2. Enter your naked root domain name (e.g., yourstore.com — do not include https:// or www).
  3. Click Continue.
  4. On the plan selection screen, scroll down to the bottom and select the Free ($0 / month) tier.
  5. Click Continue to let Cloudflare scan your existing DNS zone.
23.3

Step 2: DNS Records & The Critical Mail Shield

Cloudflare will automatically import your existing DNS records. Carefully inspect the Proxy status toggle for each row:

Type Name Target / Content Proxy Status Action
A yourstore.com 192.0.2.1 (Your Hosting IP) Proxied (Orange) Keep Proxied
A demo 192.0.2.1 Proxied (Orange) Keep Proxied
CNAME www yourstore.com Proxied (Orange) Keep Proxied
CNAME / A mail yourstore.com or Server IP DNS only (Grey) MUST BE GREY
A ftp 192.0.2.1 DNS only (Grey) Set to DNS only
MX yourstore.com mail.yourstore.com (Priority 0) DNS only (Grey) DNS only (Auto)
CRITICAL NOTICE: Do Not Proxy Your Mail Record!

Cloudflare's HTTP proxy handles web traffic on ports 80/443 only. It does not proxy email protocols (SMTP port 25/465, IMAP 993, POP3 995). If your mail or MX record is left on Orange Cloud (Proxied), your store will immediately stop receiving and sending customer order notification emails! Always click the toggle to set mail to Grey Cloud (DNS only).

After verifying that mail is set to DNS only, click the blue "Continue to activation" button.

23.4

Step 3: Nameserver Delegation & Registrar Lock

Cloudflare will assign you two designated Anycast nameservers. For example: 

Nameserver 1: ada.ns.cloudflare.com
Nameserver 2: burt.ns.cloudflare.com
How to Update at Your Registrar:
  1. Log into the registrar portal where you purchased your domain (e.g., Namecheap, GoDaddy, Hostinger, Parknil).
  2. Navigate to Domain Management → Nameservers.
  3. Select "Use Custom Nameservers".
  4. Remove your old hosting nameservers and paste Cloudflare's two nameservers into slot 1 and 2. Ensure slots 3 and 4 are completely empty.
  5. Click Save Changes.
  6. Return to Cloudflare and click "I updated my nameservers" (or "Check nameservers now").
Troubleshooting: "Changes Saved Successfully" but Old Nameservers Revert Back?

If your domain registrar interface displays "Changes Saved Successfully", but upon reloading you still see the old nameservers, your domain has Registrar Lock (ClientTransferProhibited) active! Go to the "Registrar Lock" tab in your registrar portal, click "Disable Registrar Lock", update the nameservers again, save, and then re-enable the lock for security.

23.5

Step 4: Military-Grade SSL/TLS & HTTPS Force

Once Cloudflare verifies your nameservers (indicated by ✅ Your domain is now protected by Cloudflare), configure end-to-end cryptographic security:

1. Encryption Mode: Full (Strict)

Navigate to SSL/TLS → Overview in the sidebar. Set the mode to `Full` or `Full (Strict)`.

Never use `Flexible`! If your origin cPanel or Laravel store has AutoSSL or forces HTTPS, `Flexible` causes an infinite browser redirect loop (ERR_TOO_MANY_REDIRECTS).
2. Edge Certificates Configuration

Navigate to SSL/TLS → Edge Certificates and enable:

  • Always Use HTTPS: ON — Auto-rewrites all unencrypted http:// requests to https://.
  • Minimum TLS Version: Set to TLS 1.2 — Blocks insecure legacy ciphers.
  • TLS 1.3: ON — Fastest modern 1-RTT cryptographic handshake.
  • Automatic HTTPS Rewrites: ON — Resolves mixed-content HTTP asset warnings.
23.6

Step 5: 2026+ Next-Gen Speed Acceleration

MartX is built for sub-second page loads. Activate these edge performance features inside your Cloudflare dashboard:

Recommended Speed Toggles:
Early Hints (103 Early Hints) Enable (ON)

Located in Speed → Settings → Content Optimization. Allows edge servers to signal critical CSS, JS, and web fonts to the browser before the origin HTML finishes rendering.

Cloudflare Fonts Enable (ON)

Rewrites Google Fonts requests so typography is delivered directly from the same domain at Cloudflare edge, eliminating render-blocking third-party DNS lookups.

HTTP/3 with QUIC Enable (ON)

Located in Speed → Settings → Protocol Optimization. Runs HTTP over UDP/QUIC, eliminating Head-of-Line packet loss delays on mobile LTE/5G networks.

0-RTT Connection Resumption Enable (ON)

Permits returning buyers who have visited your store previously to transmit requests on TLS handshake round-trip 0, delivering zero-wait checkout and browsing speeds.

23.7

Step 6: Automated Bot & Scraping Defense

To ensure aggressive scrapers and malicious bots do not exhaust your hosting CPU and database connection pool:

  1. In the Cloudflare left sidebar, click Security → Settings.
  2. Under the Bots section, switch Bot Fight Mode to ON.
  3. Ensure the baseline Security Level is set to Medium (optimal for production e-commerce operations).
