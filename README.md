## 💎 Architectural Highlights

* **Automated Web Installer:** Zero command-line setup. Automatically validates server readiness, connects MySQL/MariaDB, and configures admin credentials.
* **Self-Healing Storage Symlink:** 1-click administrative storage link regeneration with cross-platform NTFS junction & Linux symlink support.
* **Edge Cloud Licensing:** Integrated with Cloudflare Workers Gateway and Cloudflare D1 distributed database for near-instant zero-cost verification.
* **Faceted AJAX Filters:** Real-time dual-slider pricing, color swatches, size buttons, brand counts, and responsive list/grid switching without page reloads.
