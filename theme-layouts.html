6.1 Theme Layout Architecture & One-Click Customizer Engine

MartX provides an enterprise-grade Dynamic Theme Layout Engine that empowers store owners and administrators to completely alter the visual presentation, navigation structure, and product card rendering across the entire storefront in 1 single click — with zero code modification, zero server downtime, and zero template recompilation overhead.

Admin Access Path

Navigate to: Admin Dashboard → Website & CMS → Theme Layouts.

Step 1
Visual Selection

Select your desired layout card from any of the 6 dedicated setting tabs.

Step 2
Live Modal Preview

Click the eye icon on any card to preview the full high-res mockup before saving.

Step 3
AJAX Persistence

Click "Save Theme Layouts" to persist settings directly into the database.

Step 4
Instant Storewide Sync

Blade layout resolvers dynamically adapt the storefront in real-time with instant cache busting.

The Header is the primary visual anchor of your e-commerce store. MartX features 3 distinct Header Architectures tailored for diverse inventory depths, branding styles, and navigation models.

Critical System Rule: Header 3 & Mega Menu Incompatibility

When Header 3 is selected, the Mega Menu Layout tab is automatically disabled in the admin panel and tagged with an N/A badge.

Why? Header 3 utilizes an exclusive Centered-Logo & Side-Drawer (Curtain Menu) navigation pattern. Traditional full-width horizontal flyout mega menus are only designed for Header 1 and Header 2.

6.8 Live Preview Modal System & AJAX Persistence Engine

MartX is built to eliminate design guesswork. Every visual layout card in the theme manager is equipped with an integrated Live Preview Modal System (preview_modal.blade.php).

1. Inspecting Visual Layouts

Hovering over any card reveals the floating "Preview" button. Clicking it instantly launches a Bootstrap 5 modal rendering a full-scale, uncompressed screenshot of that specific layout in action.

Zero Commit Risk: Administrators can inspect headers, menus, and cards in crystal-clear fidelity before making any live changes to the active store.

2. Instant Persistence & Cache Management

When the administrator clicks "Save Theme Layouts", the changes are instantly synchronized in the background without reloading the page.

  • Settings are securely saved and applied globally across the storefront.
  • Storefront caches are automatically updated for immediate customer visibility.
  • An interactive SweetAlert confirmation toast notifies the user of immediate activation.
