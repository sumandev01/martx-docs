Chapter 6: Media Manager & Central Asset Hub

6.1 All Media Gallery & Asset Workspace

High-converting e-commerce relies heavily on rich visual imagery. In MartX, media assets are not scattered across disconnected folders. Instead, the Media Manager serves as the central operational hub for all product photography, category icons, brand logos, hero banners, and brand storytelling visuals.

Admin Panel — Media Manager: All Media Gallery Grid
Media Library
All Media Gallery Grid (images/media/admin_media_gallery.png)
Live view of registered assets showing file thumbnails, exact file sizes in KB, Select All checkbox, and Bulk Delete controls. MartX v1.0.0
Admin Access Route

Navigate to: Admin Dashboard → Media Manager → All Media. To add new assets, click the + Add New Media button located in the top-right toolbar.

Gallery Toolbar & Display Capabilities
Select All & Bulk Delete

Admins can check Select All to highlight multiple obsolete files across the repository, followed by initiating an instant bulk deletion to free up server disk capacity.

Dual View Switching

Toggle between high-resolution Grid View (large visual image cards with file size indicators) and a compact List View for high-density catalog inspections.

Native WebP Thumbnails

Every uploaded file automatically displays its storage footprint (e.g. 20.01 KB, 60.18 KB), enabling administrators to identify oversized assets before publishing.

Adding catalog items in bulk requires an ultra-fast asset ingestion pipeline. The Add New Media canvas allows administrators to batch upload dozens of product images, banners, or icons simultaneously through an asynchronous drag-and-drop dropzone.

6.4 Universal Media Picker Modal — Gallery Workspace

The most powerful feature of the MartX asset system is the Universal Media Picker Modal. Instead of navigating back and forth between different administrative screens, whenever an admin edits a Product, Slider, Banner, Category, Brand, or Team Member, clicking "Select Image" triggers this responsive modal instantly.

Admin Panel — Universal Media Picker: Gallery Tab Selection
In-Form Modal
Universal Media Picker Modal (images/media/admin_media_modal_select.png)
Selected image highlights with an active purple border; right column renders real-time Selection Preview with green "Insert Media" confirmation. MartX v1.0.0
3-Step Modal Selection Workflow
1. Click to Select Browse the paginated AJAX gallery (showing 96 assets per page) and click the target image. An active purple border instantly locks the selection.
2. Inspect Selection Preview The right-hand column dynamically displays the full asset preview, confirming you have chosen the exact color variant or photo.
3. 1-Click Insert Click Insert Media. The modal closes automatically, binding the asset to your active form without page reloading!

6.5 Universal Media Picker Modal — In-Form Direct Upload

What happens if an administrator is halfway through writing a complex product description or configuring a promotional banner and discovers the required image has not yet been uploaded? In legacy platforms, users lose their work by navigating away. In MartX, the Upload New tab allows direct uploading inside the modal without losing a single character of unsaved form data.

Admin Panel — Universal Media Picker: Direct In-Form Upload Tab
In-Modal Upload
Modal Upload Tab (images/media/admin_media_modal_upload.png)
Dropzone embedded directly inside the modal with dedicated "Upload Media" action for zero-friction asset ingestion. MartX v1.0.0
Zero-Disruption Workflow Principle

When you drop an image into the Upload New tab and click Upload Media, MartX securely uploads the file via background AJAX, automatically adds it to the central library, and switches back to the Gallery tab with the newly uploaded image pre-selected. You can click Insert Media immediately!

6.6 Enterprise Asset Guidelines & Performance Hygiene

To ensure blazing-fast storefront page loads (under 1.2s on mobile devices) and top Core Web Vitals scores, adhere to these production asset standards when uploading media to MartX:

Modern WebP Adoption

Utilize WebP format for all catalog photography. WebP reduces file weights by 60% to 80% compared to legacy PNG/JPG while retaining 100% visual fidelity.

1:1 Aspect Ratio

Format product main images and team headshots in square ratios (e.g. 600x600 px or 800x800 px) to prevent irregular masonry jumps in storefront grids.

Descriptive Alt Text

Always provide meaningful Alt Text containing product colors, brand, and type (e.g. "women-leather-tote-bag-beige") to capture free Google Image traffic.

Periodic Bulk Hygiene

Every quarter, review the All Media gallery. Use Select All and Bulk Delete to purge expired seasonal banners and test uploads.
