Background Maintenance & Storefront Automation

A thriving eCommerce store operates non-stop. While customers browse and purchase products, several essential background tasks must run continuously behind the scenes. The MartX Automation Engine ensures that expired unpaid checkout sessions are promptly cancelled, locked product quantities are returned to available stock, promotional flash sale timers trigger on schedule, and system caches remain optimized.

Supported Automation Methods:
• Method A: Standard Hosting Scheduled Task (cPanel Cron Jobs)
• Method B: 1-Minute Free Cloud Web Cron (cron-job.org / EasyCron / Cloudflare)

22.1 What Background Tasks Do for Your Store

When customers initiate an online payment via Stripe or payment gateways, MartX temporarily holds the product inventory to prevent overselling. If the buyer abandons checkout or closes their browser, the background task engine automatically restores stock availability.

Key Automation Responsibilities
Cancelling Abandoned Unpaid Orders

Automatically scans for pending orders that have exceeded payment expiration windows, marks them as cancelled, and instantly restores the reserved product quantities back to live stock.

Promotion & Flash Deal Timers

Ensures promotional banners, coupon validity periods, and flash sales start and conclude strictly according to your local store timezone without requiring manual admin intervention.

Email Delivery Reliability

Manages outbound customer email queues, review notification dispatches, and contact message notifications so your hosting server never experiences request timeouts.

System Cache Optimization

Flushes expired temporary session tokens, prunes stale shopping carts, and optimizes database query performance for ultra-fast customer page load speeds.

22.2 Method A: Standard cPanel Scheduled Task Setup

If your store is hosted on a standard cPanel hosting server (e.g. Namecheap, Bluehost, Hostinger, Siteground, cPanel VPS), follow this simple 4-step walkthrough:

Step-by-Step cPanel Configuration
  1. Log into your Hosting cPanel: Navigate to your hosting client portal and open the cPanel dashboard for your domain.
  2. Find Cron Jobs: In the search box at the top of cPanel, type Cron Jobs and click on the Cron Jobs icon (located under the Advanced section).
  3. Select Schedule Frequency: In the Common Settings dropdown menu, select Once Per Minute (* * * * *).
  4. Enter the Scheduled Command: In the Command input field, paste the standard command below (replace your_username with your actual cPanel username):
    php /home/your_username/public_html/artisan schedule:run >> /dev/null 2>&1
    Note: If your store is installed in a subdomain or folder, adjust public_html to match your root folder path.
  5. Save Scheduled Task: Click the Add New Cron Job button. cPanel will now automatically trigger background maintenance every minute!

22.3 Method B: Zero-Code Cloud Web Cron Setup & Anti-DoS Security Shield

If your hosting plan does not include cPanel cron jobs, or if you prefer a completely visual, zero-code setup, MartX features a dedicated Secure Web Cron Endpoint. It allows reliable background maintenance without terminal commands or server root access.

Your Secure Store Web Cron URL

MartX includes a protected web trigger URL that safely executes background tasks when visited. Simply copy your store's web cron link:

Default Web Cron Trigger URL: https://yourdomain.com/run-background-tasks/YOUR_SECRET_TOKEN
Custom Secret Bearer Token

You can customize your secret key at any time in your store environment configuration (CRON_TOKEN). Any request using an unauthorized or guessed token is instantly rejected with an HTTP 403 Forbidden response.

3-Request/Minute Anti-DoS Shield

To guarantee your server CPU remains safe from traffic floods or malicious bot pings, the web cron enforces a strict rate limit of 3 requests per minute (CRON_RATE_LIMIT=3). Exceeding requests are immediately stopped with an HTTP 429 Too Many Requests notice.

Tailored Payment Gateway Auto-Cancellation Windows

Rather than using an arbitrary flat timer, MartX automatically protects store inventory based on the actual session expiration policies of each payment network:

Payment Gateway Auto-Cancel Window Protection Rationale
CoinGate (Cryptocurrency) 22 Minutes Matches the 20-minute blockchain rate invoice lock plus a 2-minute mempool broadcast buffer.
Stripe & SSLCommerz 32 Minutes Matches the 30-minute bank checkout expiration plus a 2-minute 3D-Secure SMS/OTP grace period.
PayPal Checkout 185 Minutes (~3 Hours) Matches PayPal's official 3-hour REST token validity plus a 5-minute network latency safety buffer.
Cash on Delivery & Bank Transfer Never Cancelled Preserved indefinitely in your orders ledger for store manager phone confirmation or manual bank slip approval.

22.4 Frequently Asked Questions & Troubleshooting Knowledge Base

Quick, authoritative answers to the most common questions and operational scenarios encountered by store owners and administrators:

Cause: On shared hosting, the connection between the private storage folder and the public web directory (known as the storage symlink) can get disconnected during server migrations or domain changes.

Instant 1-Click Fix: You do NOT need terminal or SSH access. Simply log into the MartX Admin Dashboard, navigate to System Settings > System Configuration, and click the Re-generate Storage Symlink button. The system will automatically repair the connection, and all your product pictures, category icons, and brand logos will display properly immediately.

Cause: Incorrect SMTP port or authentication credentials in your mail configuration.

Solution: Navigate to System Settings > Mail Settings and check the following rules:

  • Port Matching: If you enter Port 465, select SSL encryption. If you enter Port 587, select TLS encryption.
  • For Gmail Accounts: You cannot use your standard account password if 2-Step Verification is active. Generate a 16-character Google App Password from your Google Account Security page and paste it into the Mail Password field.
  • For Webmail (cPanel): Ensure the From Address matches your domain (e.g., orders@yourdomain.com) to prevent emails from going to spam.

Solution: Navigate to System Settings > Security & Access. In the Admin URL Prefix field, enter any custom path (for example, my_private_hub or staff_portal) and save.

MartX will immediately move your login page to the new URL (e.g., https://yourdomain.com/my_private_hub). Anyone trying to guess standard paths like /admin or /wp-admin will see a 404 Not Found error.

Solution: MartX is built with native integration for Google Gemini 1.5 Flash, which has a 100% free tier (up to 15 requests per minute with zero billing required):

  1. Visit aistudio.google.com/app/apikey and sign in with your regular Google account.
  2. Click Create API Key and copy your key.
  3. Go to your Admin Dashboard > System Settings > AI & Live Chat, switch Enable AI Chat to ON, paste your API key, and click Save Changes.
  4. A modern floating AI chat assistant will now appear on your storefront to help customers find products and answer shopping inquiries!

Solution: You do NOT need to contact support or modify database tables. MartX includes automated 1-Click Domain Relocation:

  1. In your current dashboard, go to System Settings > License & Verification.
  2. In the License Key Re-binding card, enter your Target New Domain and click Send 1-Click Confirmation Link.
  3. Check your registered buyer email and click the confirmation link.
  4. Your license is immediately unbound from the old domain and activated on your new domain with zero downtime. (See Chapter 4 for full details).

  • Choose from 7 curated Google Font families (Plus Jakarta Sans, Inter, Outfit, Poppins, etc.) to instantly change typography storewide.
  • Select from 9 luxury color skin presets or use the custom hex color pickers to match your brand palette.
  • Toggle the Theme Switcher ON or OFF, and select whether new shoppers see Light Mode or Dark Mode by default.

Solution: MartX features an automated dynamic XML sitemap located at https://yourdomain.com/sitemap.xml.

  • Zero Maintenance: All published products, categories, subcategories, brands, CMS pages, and blog posts are compiled automatically.
  • Smart 24-Hour Cache: The sitemap XML is cached in server memory for 24 hours to prevent database load from search bot crawlers.
