1.11 Two-Factor Authentication (2FA) & 5 Emergency Recovery Codes

MartX delivers enterprise-grade multi-factor security for administrator accounts, pairing real-time email verification with cryptographically secure emergency bypass mechanisms:

6-Digit Email OTP Challenge

When 2FA is activated, every administrative sign-in requires a dynamic 6-digit one-time verification code dispatched directly to your authorized administrator email address with an automated security expiry timer.

Mandatory SMTP Handshake

To prevent accidental administrator lockout due to invalid mail configurations, 2FA cannot be toggled on without successfully passing an interactive live test OTP handshake.

5 Emergency Backup Codes

Generates 5 single-use emergency backup recovery codes (e.g. A1B2-C3D4) stored securely with encryption. Includes 1-click clipboard copy and text file download. In case of mailbox downtime, entering a backup code grants instant access.

Disaster Recovery: Emergency 2FA Lockdown Bypass (Database Reset)

In the rare emergency where the administrator loses access to their mailbox and has misplaced all 5 backup recovery codes, you are never locked out. As a technical administrator (via cPanel phpMyAdmin or database manager), you can instantly deactivate 2FA with zero downtime by switching the 2FA status key to 0 in the settings table.

Real-Time Emergency Reset: The authentication engine checks database status in real-time during admin sign-in. The moment the status is reset in phpMyAdmin, 2FA is immediately deactivated without requiring terminal commands or server restarts.

Smart Anti-Fraud Hybrid Cash on Delivery (Advance Delivery Charge System)
Eliminate fake orders and return shipping losses with configurable upfront fulfillment charge
Admin Navigation: Admin Sidebar → Ecommerce & Sales → Payment Gateways → Cash on Delivery (Click Edit)

The greatest operational risk in digital commerce merchandising is fraudulent or uncollected Cash on Delivery shipments where merchants absorb double return delivery costs. MartX eliminates this vulnerability through an intelligent Hybrid Cash on Delivery system:

1. Standard Pure COD Mode (Status: Disabled / Off): When the Advance Shipping switch is toggled OFF, customers place orders with zero upfront payment. The full gross invoice amount is collected at doorstep delivery.
2. Mandatory Upfront Delivery Charge Mode (Status: Enabled / On): When toggled ON, customers must pay the delivery/shipping charge upfront during checkout to confirm order placement, while paying the remaining product bill safely on doorstep delivery.
Omni-Channel Advance Payment Channels: Merchants easily select which gateways are permitted to receive advance shipping charges using the Allowed Advance Gateways multi-select checkboxes. Customers choose between any of the active online gateways (Stripe, PayPal, SSLCommerz, CoinGate) or Direct / Manual Payment (bKash, Nagad, Rocket, Bank Transfer with Sender Number & Transaction ID verification). The order status automatically updates to Shipping Paid with verified advance payment confirmation in the admin order list.

Automated Background Payment Sync & Fraud Shield
Zero lost orders even if buyers close their browser before return redirects execute

Traditional online stores risk dropped orders when buyers close their browser immediately after paying. MartX completely protects merchants through automated direct server-to-server payment notifications:

Cryptographic Signatures:

Payment notifications are cryptographically verified directly with gateway servers (Stripe, PayPal, SSLCommerz, CoinGate) to ensure every transaction confirmation is genuine.

Anti-Price Tampering:

Background listeners strictly compare the actual paid amount against the order grand total. Any tampered or mismatched amount is flagged immediately for merchant review.

Duplicate Order Prevention:

Automated transaction locking ensures that if a customer redirect and a background webhook notification arrive simultaneously, the order is confirmed once and only once with zero duplicates.
