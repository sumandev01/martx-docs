Upload the `martx-v1.0.0.zip` package to your cPanel or server webroot (`public_html`) and extract all files.

Log in to your 360° Admin Cockpit, select your store currency, configure payment gateways, and start processing customer orders immediately.

## 1.11 Two-Factor Authentication (2FA) & 5 Emergency Recovery Codes

* **6-Digit Email OTP:** Every administrator login generates a dynamic one-time code sent to the verified administrator mailbox.
* **Mandatory Live SMTP Handshake:** 2FA cannot be enabled without a successful test OTP delivery, preventing accidental lockouts caused by incorrect email credentials.
* **5 Single-Use Emergency Recovery Codes:** Cryptographically generated backup codes stored with AES-256 encryption. Features 1-click clipboard copy and text file download.
* **Disaster Recovery Database Bypass:** If an administrator loses mailbox access and misplaces recovery codes, changing the 2FA flag to `0` in the database settings table deactivates 2FA instantly with zero downtime.
