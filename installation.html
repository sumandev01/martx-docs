Chapter 3: Installation & Deployment Guide

Deploying MartX Enterprise Platform is effortless. Built with an intuitive WordPress-style 5-Step Web Installation Wizard, merchants and agencies can launch a production-ready store within 3 minutes without touching command-line scripts.

3.1 Deployment Pathways & Pre-Installation Checklist

Choose the deployment pathway that best matches your hosting infrastructure:

Deployment Method Target Infrastructure Skill Level Setup Time Recommended For
cPanel Quick Deploy cPanel / DirectAdmin / Plesk Standard 5 Mins Shared hosting users using File Manager and MySQL Wizard.
5-Step Web Wizard cPanel / Shared / VPS / Localhost No-Code (Beginner) 3 Mins All store owners, designers, and standard marketplace buyers.
VPS CLI / DevOps Ubuntu / Debian / Nginx / Forge Advanced 4 Mins Agencies, high-traffic stores, and continuous deployment workflows.
phpMyAdmin Fallback Any MySQL GUI / Offline Localhost Manual Fallback 5 Mins Environments where automated migrations encounter timeout restrictions.
Pre-Installation Checklist (Have These Ready)
  • Marketplace Purchase Code: Your official Item Purchase Code or Order ID from CodeCanyon, Codester, TemplateMonster, or Direct Invoice.
  • MySQL Database Credentials: Database Host (usually 127.0.0.1 or localhost), Database Name, Database Username, and Password.
  • PHP 8.2+ Environment: Server meets the 13 mandatory PHP extensions outlined in Chapter 2.

3.2 cPanel & Shared Hosting 5-Minute Quick Setup

Before launching the browser installer, upload the application files and configure your MySQL database in cPanel:

Step 1: Upload and Extract Zip Archive

Open cPanel → File Manager, navigate to your desired directory (e.g. /public_html for primary domain, or a subfolder like /public_html/your-subfolder), upload the official martx-v1.0.0.zip file, right-click and choose Extract.

Step 2: Configure DocumentRoot to Point to public/

Laravel applications require web traffic to resolve in the public/ folder:

  • Subdomains & Addon Domains: In cPanel → Domains → Document Root, set the path to public_html/public or public_html/subdomain_name/public.
  • Primary Main Domain (Root): Either configure the Primary Document Root in cPanel, or place files in root and point the web root to public/.
Step 3: MultiPHP Manager & Version Selection

In cPanel → MultiPHP Manager, select your domain and choose PHP 8.2 or PHP 8.3.

Step 4: Create MySQL Database via cPanel Wizard

In cPanel → MySQL Database Wizard:

  1. Create a new Database (e.g., cpaneluser_martx).
  2. Create a Database User with a strong password.
  3. Assign ALL PRIVILEGES to the user for that database.
Step 5: Proceed to Web Installer Wizard

Once your files are extracted and database credentials are created, open your browser and visit https://yourdomain.com/install to complete the 5-step visual installer below!

3.4 Ubuntu VPS & Developer CLI Installation

Optional • For DevOps & Cloud Engineers
Merchant Note: If you are using cPanel or shared hosting, you do not need terminal commands! Simply use the 3-minute visual web installer at https://yourdomain.com/install (detailed in Sections 3.2 & 3.3).

For agencies, DevOps engineers, and cloud administrators deploying via SSH terminal, MartX provides a dedicated interactive CLI installation command allowing complete setup directly from the command-line without opening a web browser:

1. Configure .env File

Copy the environment template and set your domain URL and MySQL database credentials: 

cp .env.example .env
php artisan key:generate

Set APP_URL=https://yourstore.com and your DB_DATABASE, DB_USERNAME, DB_PASSWORD.

2. Run MartX CLI Installer

Run the automated terminal setup command in interactive mode: 

php artisan martx:install

Prompts for your Purchase Code, verifies licensing, migrates tables, seeds demo data, and provisions the Super Admin account!

Headless CI/CD & Automated 1-Liner Deployment

You can also pass flags directly to martx:install for zero-prompt, fully unattended CI/CD deployment pipelines: 

php artisan martx:install --license="YOUR-PURCHASE-CODE" --email="buyer@domain.com" --admin-email="admin@yourdomain.com" --admin-password="YourStrongPassword123"
Ubuntu Server Permissions & Symlink Script
Ubuntu 24.04 / 22.04 LTS Deployment Script 
# 1. Navigate to project root
cd /var/www/html/martx

# 2. Install production dependencies
composer install --no-dev --optimize-autoloader --no-interaction

# 3. Create storage symlink
php artisan storage:link

# 4. Set web server permissions
sudo chown -R www-data:www-data /var/www/html/martx
sudo find /var/www/html/martx -type f -exec chmod 644 {} \;
sudo find /var/www/html/martx -type d -exec chmod 755 {} \;
sudo chmod -R 775 storage bootstrap/cache

# 5. Compile production performance caches
php artisan optimize

3.5 Storage Symlink (storage:link) 3-Tier Multi-Layer Architecture

Product photography, banner slides, and customer invoices are securely stored in storage/app/public/. To make them visible to web visitors, a symbolic link must exist between public/storage and storage/app/public. MartX provides a comprehensive 3-tier fail-safe solution:

Tier 1
100% Automatic at Install

Built-in WordPress-style automation. The Web Installer (Step 5) and CLI command (martx:install) silently create the symlink during setup. 95% of store owners never need to touch anything!

Tier 2
1-Click In-Dashboard Fix

If you ever migrate hosting or restore a cPanel backup, go to Admin Sidebar → Administration & Settings → System Settings → "Theme & Appearance" (Tab). The live health badge indicates symlink status, with a 1-click "Generate Public Symlink" button.

Tier 3
Terminal & cPanel Cron

For DevOps engineers on SSH or servers with locked functions, run php artisan storage:link or create a 1-time cPanel cron task: /usr/local/bin/php /path/artisan storage:link.

3.6 Subdomain, SSL (HTTPS) & APP_URL Configuration Standards

To prevent Mixed Content warnings and CSRF security token mismatches, ensure your environment URL strictly matches your live domain protocol:

Deployment Type Recommended Pattern Target APP_URL in .env
Primary Root Domain https://yourstore.com APP_URL=https://yourstore.com
Dedicated Subdomain (Recommended) https://shop.yourdomain.com APP_URL=https://shop.yourdomain.com
Local Development http://martx.test or http://localhost:8000 APP_URL=http://martx.test

3.7 Post-Installation Security Hardening & Lock Verification

Once the 5-step installer wizard completes, the system executes an automated security lockdown to safeguard your store:

Automatic Installer Lockdown Engine

The installer writes the file storage/installed and establishes secure verification tokens. Subsequent requests to /install are permanently blocked and redirected to the home storefront to prevent unauthorized database resets.

Production 1-Click Optimization Command

For blazing-fast performance and sub-50ms response times, run the optimization compilation command: 

# Clear and rebuild all compiled routes, configs, and Blade views
php artisan optimize
