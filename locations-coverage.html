Chapter 20: Geographic Locations & Delivery Coverage Zones

Configuring multi-national delivery zones, 1-click cloud state synchronization, ISO Alpha-2 country standards, interactive province management, and dynamic checkout address cascades.

1-Click Online State Sync

Automated integration with global geo-APIs (countriesnow.space) to ingest hundreds of states/provinces in seconds.

ISO-2 Flag Standards

Standard 2-letter uppercase country codes (BD, US, GB, CA, DE, AU) enabling automatic flag rendering and payment gateway compliance.

Interactive State Tags

Visual, removable state badges with overflow counters (+X more) for frictionless regional delivery zone curation.

Geographic Hierarchy & Commerce Architecture

Delivery accuracy is the foundation of successful eCommerce fulfillment. The MartX Locations & Coverage Engine provides a robust relational hierarchy connecting Country > State / Province / Division > Shipping Couriers. This ensures that customers at storefront checkout only see valid shipping destinations, allowing store managers to define exact coverage boundaries and avoid costly out-of-coverage delivery failures.

Admin Navigation Paths:
• Admin Dashboard > Administration & Settings > Locations > All Locations
• Admin Dashboard > Administration & Settings > Locations > Add Location

20.2 Automated 1-Click Online State Synchronization

Manually typing dozens of states, provinces, or prefectures for multiple countries is tedious and error-prone. MartX incorporates a built-in 1-Click Online State Synchronization Engine powered by the global countriesnow.space API.

The Cloud Sync Execution Pipeline
1
Select Target Country

In the right-hand Sync States From Online card, choose any registered country from the dropdown list (e.g., Germany, Canada, Australia).

2
Trigger Cloud Ingestion

Click Sync States. The backend dispatches a secure HTTP POST request to https://countriesnow.space/api/v0.1/countries/states with the country payload.

3
Deduplicated Ingestion

The repository processes the API response via State::firstOrCreate(), inserting only non-existing states while preserving existing IDs and courier mappings.

Merchant Benefits: Automated vs Manual Data Entry
100% Zero Manual Typing

Instead of spending hours manually researching and typing 50 US states, 16 German Bundesländer, or 10 Canadian provinces, simply select the country from the dropdown and click Sync States.

Smart Duplicate Prevention

The cloud sync engine automatically checks existing records before saving. You can safely trigger the sync button anytime without creating duplicate regions or disrupting active shipping rules.

Zero Duplication Guarantee

Because synchronization relies on firstOrCreate based on unique compound keys (country_id + name), you can click Sync States multiple times without creating duplicate entries or corrupting customer shipping addresses.

20.4 Storefront Checkout Cascades & Courier Integration

The locations configured in this module directly govern the checkout experience on your MartX storefront. When a shopper places an order, the address selection flow executes a dynamic, responsive AJAX cascade.

Checkout Address Cascade Flow
1. Customer Selects Country

2. Instant State Loading

3. Accurate Shipping Rates

20.5 International Expansion & Coverage SOP

Follow these enterprise standard operating procedures when expanding your eCommerce store to new international markets or restricting shipping during regional logistics disruptions.

SOP: Launching a New International Market
  1. Verify shipping courier rates and lead times with DHL, FedEx, or local logistics partners (see Chapter 10: Couriers & Shipping Costs).
  2. Navigate to Add New Location and register the destination country with its official ISO Alpha-2 code (e.g., FR for France, JP for Japan).
  3. Return to Location Management and use Sync States From Online to automatically import all provinces or prefectures in one click.
  4. Assign relevant shipping costs in the Courier configuration. Customers in that country can now place orders immediately.
SOP: Restricting Affected Delivery Zones
  • In the event of regional weather disruptions, strikes, or courier suspensions in a specific province (e.g., remote territories), find the country row in the master table.
  • Click the small × button on the specific state badge (e.g., Bavaria ×). The state is removed from checkout eligibility instantly.
  • Checkout attempts from that region will display a helpful customer notice: "We currently do not ship to the selected state."
  • Once logistics resume, re-add the state manually in 10 seconds via Add State (Manual).
